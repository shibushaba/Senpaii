# CDK Learning

1. Capture observations before interpreting them.
2. Link experiences to source files, commands, test outputs, or user-confirmed facts.
3. Separate facts, hypotheses, recommendations, and unknowns.
4. Keep lessons proposed until verification criteria are satisfied.
5. Retrieve project memory with status and limitations.
6. Treat global promotion as a separate, human-approved workflow.
7. Never store secrets, customer personal data, access tokens, or production payloads.
