# API / Integration Gate

- [ ] Contract and error semantics are documented.
- [ ] Authentication and resource authorization are enforced.
- [ ] Input validation and output schemas are defined.
- [ ] Timeouts and bounded retry behavior exist where appropriate.
- [ ] Side effects are idempotent or deduplicated where needed.
- [ ] Webhook authenticity/replay protection is considered.
- [ ] Secrets remain server-side.
- [ ] Rate limits, quotas and degraded behavior are considered.
- [ ] Contract/integration tests cover important cases.
