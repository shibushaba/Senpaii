# Release Readiness Gate

- [ ] Scope, target environment and release owner are clear.
- [ ] Relevant tests and build checks passed or exceptions are approved.
- [ ] Configuration and secrets are available in target environment.
- [ ] Migrations are ordered and compatible.
- [ ] Backups and restore path are understood for data-impacting releases.
- [ ] Health checks, logs, metrics and alerts are adequate.
- [ ] Background jobs, queues and webhooks are considered.
- [ ] Rollback/forward-fix and stop conditions are defined.
- [ ] User/support communication is ready where needed.
- [ ] Explicit authorization exists before deployment.
