# Security First-Pass Gate

- [ ] No secrets were introduced or exposed.
- [ ] Authentication and server-side authorization were reviewed.
- [ ] Object-level and tenant-level access were considered.
- [ ] Inputs are validated and queries are parameterized.
- [ ] Output encoding and injection risks were considered.
- [ ] Sensitive data is not unnecessarily logged.
- [ ] Dependencies and configuration were reviewed within scope.
- [ ] Rate limiting and abuse controls were considered.
- [ ] Webhooks, uploads, redirects and cross-origin behavior were reviewed where applicable.
- [ ] Findings distinguish confirmed issues from unverified concerns.
