# Incident Review Gate

- [ ] User/system impact and time window are defined.
- [ ] Timeline is evidence-based.
- [ ] Facts, hypotheses and unknowns are separated.
- [ ] Sensitive data is redacted.
- [ ] Containment and recovery are validated.
- [ ] Contributing factors are described without blame.
- [ ] Follow-up actions have measurable outcomes.
- [ ] Production changes have appropriate authorization.
