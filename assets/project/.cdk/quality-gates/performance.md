# Performance Gate

- [ ] Symptom and target metric are defined.
- [ ] Baseline was measured or limitation disclosed.
- [ ] Bottleneck is supported by evidence.
- [ ] Correctness and consistency are preserved.
- [ ] Memory, CPU, database and network effects were considered.
- [ ] Before/after measurement uses comparable conditions.
- [ ] Cache invalidation and operational complexity are considered.
- [ ] Load testing is not run against production without approval.
