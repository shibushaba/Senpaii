# Pull Request Gate

- [ ] Branch and working tree were inspected.
- [ ] Diff contains only intended changes.
- [ ] No secrets, local files or debug artifacts are included.
- [ ] Tests and checks are listed with actual outcomes.
- [ ] Breaking changes and migrations are called out.
- [ ] User-visible behavior is described.
- [ ] Risks and follow-up work are disclosed.
- [ ] Commit/push/PR creation has explicit authorization.
